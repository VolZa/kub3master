04_Catalog — службовий довідник (Template Catalog) для створення елементів.

Архітектурні принципи
04_Catalog є службовим довідником шаблонів типів елементів.
04_Catalog використовується лише під час створення або імпорту елементів у 00_Elements.
00_Elements є канонічним довідником усіх конкретних елементів ERP.
Після створення елемента ERP працює виключно з даними 00_Elements.
Матеріали та деталі є глобальними.
Складальні одиниці та вироби належать конкретному документу проєкту.
Проєкт визначається через ProjectDocument.
