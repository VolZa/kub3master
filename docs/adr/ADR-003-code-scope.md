ADR-003 — Коди елементів унікальні лише в межах ProjectDocument.
Проблема

У різних альбомах проекту можуть існувати деталі
з однаковими позначеннями.

Приклад

КР.3 → ГС-2

КР.9 → ГС-2

Рішення

Код елемента унікальний лише в межах ProjectDocument.

Глобальна ідентифікація здійснюється через

Project

- ProjectDocument
- Code

Причина

ERP повинна повторювати структуру проектної документації,
а не вводити штучні глобальні коди.

Наслідки

Усі Repository повинні враховувати ProjectDocument.
