ADR-025 — ProjectDocument як виробничий контекст

Контекст

ERP підтримує декілька проєктів та будинків.

Потрібно визначити єдиний контекст, який використовуватиметься всіма виробничими модулями.

Рішення

Усі виробничі модулі використовують ProjectDocumentID як основний контекст.

00_Elements містить ProjectDocumentID, який однозначно визначає належність елемента до документа проєкту.

Таблиця 19_ProjectDocuments забезпечує два види пошуку:

ID → ProjectID, Code, Name
(ProjectID, Code) → ID

Таблиці 18_Projects та 20_Houses використовуються для організації даних, вибору користувачем, навігації та формування звітів, але не є частиною виробничого контексту.

Наслідки
Усі виробничі модулі (Import, BOM, Placement, Production, Materials, Planning) працюють із єдиним ключем ProjectDocumentID.
Бізнес-логіка не залежить від структури проєктів і будинків.
Зменшується кількість міжмодульних залежностей.
Спрощується підтримка багатопроєктності.
