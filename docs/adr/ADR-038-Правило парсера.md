Кутник

2 числа → рівнополичковий
width = height

3 числа → нерівнополичковий
width ≠ height

           Це правило просте, відповідає кресленням і дозволяє однозначно отримувати правильний Material Code. Такий підхід буде зручним для технолога і водночас збереже однозначність внутрішньої моделі ERP.

У виробництві всі звикли говорити:

Кутник 100×7
Кутник 75×6
Кутник 125×8

і лише для нерівнополичкових уточнюють:

Кутник 100×63×8
Кутник 125×80×10

Тобто ERP буде використовувати звичну для технолога нотацію, а внутрішньо автоматично перетворюватиме її на повний опис геометрії.

Правило уточнення профілю

04_Catalog містить загальний ProfileType.
Парсер може уточнити його після аналізу геометрії.
Подальші сервіси (MaterialCodeBuilder, MaterialResolver) працюють уже з уточненим ProfileType.
