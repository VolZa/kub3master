13_Placement є єдиною канонічною моделлю виробничих екземплярів виробів.

Context

Проектна специфікація містить кількість виробів (Qty).

Для виробництва кожен виріб повинен існувати як окремий екземпляр.

Decision

Технолог перетворює записи специфікації на окремі записи Placement.

Після цього всі виробничі модулі працюють виключно з Placement.

Consequences
Production
Material Usage
Shipment
Installation
Warehouse

ніколи не працюють із Qty.

Вони працюють лише з окремими екземплярами виробів.
