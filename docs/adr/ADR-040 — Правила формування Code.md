Принцип 1

Code є канонічним ідентифікатором ERP і не залежить від локалі користувача.

Принцип 2

Усі числові значення всередині Code записуються через крапку (.) як десятковий роздільник.

Приклади:

WIRE_1.2_OB
PR_34_2.5
PR_89_3.5

незалежно від того, що користувач ввів

1,2

або

1.2
Принцип 3

Символ \_ використовується лише як роздільник параметрів Code.

Принцип 4

Усі введені користувачем числа проходять два етапи.

Принцип 5

Жоден Builder не працює з рядком користувача.

Builder отримує вже нормалізовані значення типу number.

Наслідки

Тепер усі Builder-и працюватимуть однаково.

RebarCodeBuilder

FlatBarCodeBuilder

AngleCodeBuilder

PipeCodeBuilder

WireCodeBuilder

ConcreteMixCodeBuilder

і кожен використовуватиме

formatNumberForCode(number)
