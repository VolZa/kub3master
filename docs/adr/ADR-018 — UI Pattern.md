ADR-018 — UI Pattern

Принцип

ERP КУБ використовує два типи інтерфейсів:

- робочі екрани — для повсякденної роботи технолога;
- модальні діалоги — для коротких завершених операцій (створення, імпорт, налаштування).

Критерії вибору

Робочий екран (Workspace)

Використовується, якщо користувач:

працює з даними тривалий час;
переглядає таблиці;
редагує записи;
аналізує інформацію.

Приклади:

Будинки;
Placement;
Матеріали;
Планування;
Звіти.

Модальний діалог (Dialog)

Використовується, якщо дія:

короткочасна;
має початок і кінець;
після завершення користувач повертається до попереднього екрану.

Приклади:

Імпорт проектної документації;
Створення будинку;
Створення проєкту;
Створення документа проєкту;
Додавання партії матеріалу.

Поточний етап розвитку ERP

Постійні довідники (Projects, ProjectDocuments, Houses) ведуться безпосередньо в Google Sheets.

ERP використовує їх у режимі читання.

Форми для їх редагування з'являються лише тоді, коли це починає спрощувати роботу користувача.
