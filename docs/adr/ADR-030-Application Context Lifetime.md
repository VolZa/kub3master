ADR-030 — Application Context Lifetime

У ньому зафіксувати:

ProjectContext створюється один раз після вибору будинку.
Контекст є незмінним (immutable).
Працює протягом усієї сесії технолога.
Змінюється лише при переході на інший будинок.
Бізнес-сервіси не змінюють ProjectContext, а лише використовують його.

Це природне продовження ADR-028 і ADR-029.
