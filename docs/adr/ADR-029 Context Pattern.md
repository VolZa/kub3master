Context Pattern

Формулювання:

Кожен бізнес-сервіс ERP працює в межах одного ProjectContext. Контекст формується один раз і передається сервісам як єдине джерело інформації про поточний будинок, проєкт і документи проєкту.

На мою думку, це буде настільки ж фундаментальний принцип, як Repository Pattern для доступу до даних. Він визначатиме спосіб взаємодії між усіма бізнес-модулями ERP КУБ.
